# OpenMazelingo

[Mazelingo](https://chromewebstore.google.com/detail/mazelingo/bhdngeocokoeblnnlhjibojcadefimpi)風の文単位バイリンガルミックス表示を、**Chrome内蔵のオンデバイス翻訳(`Translator` API, Gemini Nano)だけ**で実現する学習用拡張機能。

**外部サーバーへの通信は一切行いません。** APIキーの入力も不要です。翻訳はすべて端末内で完結します。

## 動作要件

- Chrome 138 以降(デスクトップ版)
- 初回利用時に ja→en(・モードによっては en→ja も)の翻訳モデル(数百MB)が自動ダウンロードされます。ダウンロード中はページを開いたままにしてください。
- モデルのダウンロード状況は `chrome://on-device-translation-internals` で確認できます。
- もし `Translator` が使えない場合は `chrome://flags` で以下を確認してください(環境によっては不要です):
  - `#translation-api`
  - `#optimization-guide-on-device-model`

## インストール方法(開発者モード)

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ (`openmazelingo`) を選択する

## 使い方

1. ツールバーのアイコンをクリックして設定パネルを開く
2. 「翻訳モード」で `JA→EN` / `EN→JA` / `両方` を選択
   - `JA→EN`: 日本語の文の一部を英訳
   - `EN→JA`: 英語の文の一部を和訳
   - `両方`: ページ内の日本語・英語どちらの文も検出し、それぞれ逆方向に変換(日英混在ページ向け)
3. 「ミックス率」スライダーで変換される文の割合(0〜100%)を調整(Splatoon風のバトルバーが対象比率で揺れます)
4. 対応ページを開くと、対象言語の文の一部が自動で変換され下線付きで表示される
5. 変換された文に**マウスを乗せると**元の文が一時的に表示される(プレビュー)
6. 変換された文を**クリックすると**表示言語がそのまま固定される(もう一度クリックで切り替え)
7. 「翻訳するページ(include)」「除外するページ(exclude)」にURLパターン(`*`ワイルドカード)を1行ずつ指定してサイトごとに制御できる。ポップアップの「このサイトを追加」ボタンで現在のサイトを簡単に追加可能
8. ページを**右クリック**すると以下のメニューが出る:
   - 「このサイトを翻訳除外リストに追加」— exclude リストに永続的に追加(ポップアップの設定にも反映される)
   - 「このタブで一時的に無効にする」— 保存はされず、そのタブをリロードすると自動的に解除される

## 仕組み

- `content.js` がページ内のテキストノードを走査し、全角(。！？)・半角(.!?)どちらの句読点でも文単位に分割
- 文ごとに日本語/英語を判定し(`mode`設定に応じて対象言語を絞り込み)、長さが妥当な文だけを対象とする(最小文字数は設定可能)
- **決定論的な文選択**: `location.href` と対象文の内容をシードにした疑似乱数(mulberry32)でシャッフルし、設定した比率ちょうどの数の文を選ぶ。ja/en それぞれ独立に選ぶので「両方」モードでもen→jaとja→enの比率は揃う。同じページなら再読み込みしても同じ文が選ばれる
- 選ばれた文を、方向に応じて `Translator.create({ sourceLanguage: 'ja', targetLanguage: 'en' })` または `{ sourceLanguage: 'en', targetLanguage: 'ja' }` で作成した翻訳インスタンスに渡して変換結果を表示。2方向のTranslatorインスタンスは独立にキャッシュされる
- `nav`/`header`/`footer`/`aside`/`role="navigation"`等/`contenteditable`/`[translate="no"]`/`.notranslate` は除外し、サイトのUI要素を誤訳しないようにする
- `MutationObserver` で動的に追加されるコンテンツ(SPA等)にも追従
- サイトの有効/無効はURLパターンのinclude/excludeリストで判定(グロブ形式、`*`がワイルドカード)

## 既知の制限

- 文分割は正規表現による簡易ロジックのため、記号や改行が複雑なページでは分割がやや不自然になることがあります
- オンデバイス翻訳の精度はクラウドの大規模LLM(GPT/Claude/Gemini等)より劣る場合があります
- `Translator` API はChromeのみ対応(Firefox/Safari等では動作しません)
- モデル未ダウンロードの状態では最初の翻訳に時間がかかります

## Mazelingoとの機能比較

実際にインストールされているMazelingo(v0.2.0)の中身を確認した結果、ストアの説明以上に多機能(音声読み上げ・ライティング添削・語彙分析・クイズ生成まで搭載)でした。OpenMazelingoは**翻訳・表示まわりに絞った軽量なオープン代替**として設計しています。

| 機能 | OpenMazelingo | Mazelingo |
|---|---|---|
| 文単位ミックス表示 | ○(決定論的選択) | ○(決定論的選択) |
| 翻訳エンジン | Chrome内蔵オンデバイスAI | ユーザー指定の外部LLM API |
| APIキー | 不要 | 必要(OpenAI/Anthropic等) |
| 通信 | 端末内のみ、外部送信なし | 選択したLLMプロバイダへ送信 |
| コスト | 無料 | LLM APIの従量課金 |
| ホバー/クリック操作 | ホバーでプレビュー、クリックで固定 | ホバーでツールチップ、クリックでアニメーション切替 |
| サイトinclude/exclude | ○(URLパターン) | ○(URLパターン) |
| 音声読み上げ(TTS) | 非対応 | ○(OpenAI TTS、要APIキー) |
| ライティング添削 | 非対応 | ○(LLMによる添削・フィードバック) |
| 語彙トラッカー/分析 | 非対応 | ○(LLMによる単語深掘り分析) |
| クイズ/状況設定モード | 非対応 | ○(LLMによるお題生成) |

TTS・ライティング添削・語彙分析・クイズ生成は生成AIタスクであり翻訳APIでは代替できないため、現時点では未実装です(必要になれば、Chrome内蔵Prompt APIでのローカル実装、または任意の外部APIキー対応を追加予定)。
