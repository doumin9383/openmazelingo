Alignment experiments

Ordered baseline は従来どおり、チャンク全文を翻訳して句読点順に対応付けます。

Strict は文ごとに個別翻訳し、対応関係を確実に保ちます。自然さ・文脈利用とのトレードオフ比較用です。

Semantic はチャンク全文を自然に翻訳した後、訳文を原言語へ逆翻訳し、意味近似で 1:1 / 1:多 / 多:1 の semantic unit に再配置します。

Chrome の Translator API が使えない環境では原文フォールバックになるため、semantic alignment の品質比較には翻訳APIが必要です。
